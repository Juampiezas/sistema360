# Sistema360

## INF-5250 Ingeniería de Software II

### Descripción

Sistema360 es un sistema de gestión empresarial desarrollado en PHP y MySQL. El sistema contiene diferentes módulos para la administración de clientes, productos, proveedores, usuarios, ventas, compras, facturación, contabilidad y reportes.

## Tecnologías utilizadas

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP
- Dompdf

## Base de datos

El proyecto utiliza MySQL como sistema gestor de base de datos.

Los archivos de la base de datos se encuentran en:

database/

## Ejecución local

1. Instalar XAMPP.
2. Iniciar Apache y MySQL.
3. Copiar el proyecto dentro de htdocs.
4. Crear la base de datos sistema360.
5. Importar el archivo SQL de la carpeta database.
6. Revisar la configuración en config/conexion.php.
7. Abrir en el navegador:

http://localhost/sistema360/
